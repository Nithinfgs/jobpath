# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep feedback about the work and not the person, and
don't harass anyone. Maintainers may remove comments or contributions that break these rules.

Report problems through the private contact on the maintainer's
[GitHub profile](https://github.com/Nithinfgs) or via a private security advisory.
